# Carver & Son, Inc. corporate website

Independent, responsive company website with corporate identity details and links to Atomic Wonders and Recall.

## Deploy using Cloudflare Pages + GitHub

1. In Cloudflare dashboard, open Workers & Pages > Create > Pages > Connect to Git.
2. Select GitHub repository `a1web/carverandson.com`.
3. Production branch: `main`.
4. Framework preset: None. Build command: `exit 0` (or leave blank). Output directory: `/` (repository root).
5. Deploy and attach custom domain `carverandson.com` **only if owned and controlled**.
6. Confirm TLS, domain binding, and public content before reporting that the site is live.

This site uses `index.html` and `Carver.jpg` in the repository root. No external build dependencies. Keep legal corporate information accurate before use in developer verification.
